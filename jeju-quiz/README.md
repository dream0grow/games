# 🍊 제주어 골든벨 퀴즈

「제11회 도전! 제주어 골든벨 예상문제」의 모든 문제(172개)를 푸는 게임.

- 목숨 없음. **모든 문제를 맞히는 것**이 목표.
- 문제가 나올 때마다 **객관식 / 주관식**이 무작위로 정해짐 (같은 문제도 다음엔 다르게).
  - 객관식: "제주어 → 뜻" 또는 "뜻 → 제주어" 중 무작위
  - 주관식: 뜻을 보고 제주어를 직접 쓰기. **ㅔ/ㅐ, 아래아까지 정확히** 맞아야 정답 (띄어쓰기·문장부호만 무시)
- 점수: 별 1개당 10점, 주관식 2배, 초성 힌트를 쓰면 절반, 틀렸다 다시 맞히면 절반, 3연속부터 보너스
- 틀린 문제는 3~5문제 뒤에 다시 나옴. 진행 상황은 브라우저에 자동 저장
- 랭킹: 공용 Supabase `scores` 테이블, `game = "jeju-quiz"`

## 아래아(ㆍ) 입력

휴대폰 자판으로는 아래아를 칠 수 없어서 주관식 화면에 **아래아 버튼판**이 있다.

1. 자음 버튼(예: `ᄒᆞ`)을 누르면 아래아 글자가 들어감
2. `+ㄹ` 같은 받침 버튼을 누르면 방금 넣은 글자에 받침이 붙음 (ᄒᆞ → ᄒᆞᆯ)
3. `ㆍ / ᆢ` 스위치로 쌍아래아(ᄋᆢ름) 입력
4. 아래아 글자 바로 뒤에 자판으로 친 자음(ㄹ 등)도 받침으로 인정

`fonts/` 의 글꼴은 Noto Sans CJK KR(SIL Open Font License)에서 옛한글 자모만 뽑은 것이다.
컴퓨터 크롬 등에서도 ᄀᆞ·ᄒᆞ가 한 글자로 모아져 보이게 한다.
