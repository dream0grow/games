# 🪵 원기둥 하나 더 넣기 (3D 수학 탐구 게임)

수학사랑 교구 **'원기둥 하나 더 넣기'**를 3D로 옮긴 단일 HTML 게임입니다.
8×5 상자에 정사각형 구조로 꽉 찬 원기둥 40개를 **하나하나 직접 옮겨서**, 정육각형(벌집) 구조로 바꾸면 41개가 들어간다는 것을 체험합니다.

## 구성

| 단계 | 내용 |
|---|---|
| ① 도전 | 캔을 끌어 옮겨 41개 넣기. 힌트 3단계, 시연 보기, 옮긴 횟수·시간 기록 |
| ② 탐구 | 정사각형 ↔ 정육각형 구조 전환, 연결 도형(노란 정사각형/정삼각형) 보기, 빈 틈 색칠, 캔을 눌러 이웃 수 세기 |
| ③ 실험실 | 상자 크기(가로 2~10, 세로 2~7)를 바꿔 "언제나 육각형이 이길까?" 확인하고 기록표 작성 |
| ④ 퀴즈 | 7문제 + 해설 |

## 조작

- 캔 누른 채 끌기: 들어 올려 옮기기 (초록 동그라미 = 놓일 자리, 빨강 = 놓을 수 없음)
- 빈 곳 끌기: 네모로 여러 캔 고르기 → 고른 캔 하나를 끌면 함께 이동 (Shift+클릭으로 추가)
- 🧲 자석: 놓을 때 이웃 캔 사이 홈에 정확히 맞춤 (끄면 자유 배치)
- 마우스 오른쪽 끌기 / 두 손가락: 화면 회전, 휠 / 손가락 벌리기: 확대
- Ctrl+Z 되돌리기, Esc 선택 해제

## 수학 요점

- 정사각형 구조: 줄 간격 1 → 8줄 × 5개 = 40개, 이웃 4개
- 정육각형 구조: 줄 간격 √3/2 ≈ 0.87 → 너비 1 + 8 × 0.87 ≈ 7.93 < 8 이라 9줄, 5·4·5·4… = 41개, 이웃 6개
- 넓은 바닥 기준 캔이 덮는 비율: 정사각형 약 79%, 정육각형 약 91%
- 작은 상자(예: 2×2)에서는 정사각형이 더 많이 들어감 → "항상"은 아님

라이브러리는 Three.js(CDN)만 사용하며, 인터넷에 연결된 브라우저에서 `index.html`을 열면 바로 실행됩니다.
